2. The split decides the headline

Neighbouring 1 s windows of one cut share the same roughness label and nearly the same signal. A random split puts them on both sides and reports R² 0.94. Holding out whole cuts gives -0.58.

5. Trial plan to simulation input decks

python -m mrl.siminput examples/grinding_plan.csv validates each row (units, ranges, speed ratio) and writes one deck per trial with derived grinding quantities (q = vs/vw, equivalent chip thickness, Q'w, contact length). Rejected rows are listed with the reason. The deck format is a template, not any company's real format.

Limits

One public dataset, 27 cuts, one bar of Inconel-625, turning (not grinding). Roughness is measured at three random points per cut, so it cannot be tied to individual windows. A negative result here says this trial set is too small and too inconsistent for a sensor model, not that sensor-based roughness models cannot work.
